# 运行文件说明

Fwoign 的本体只有 `Fwoign.exe`。它依赖几个第三方组件才能工作，这些组件**不随仓库或发行包提供**，
需要你按本文自行准备，放到程序目录下对应的文件夹里。

> 为什么不分发：`bzImage` / `init.xz` 属于 FOG 的构建产物，Tiny PXE 为第三方免费软件，
> haneWIN NFS 是**商业软件**（需自行购买授权），udpcast 为第三方 GPL 组件。
> 由使用者自行获取，既避免授权问题，也能保证你拿到的是官方最新版本。

---

## 一、三步准备

1. 把发行包解压到任意目录（下面称「程序目录」，例如 `D:\Fwoign\`）；
2. 按第二节的清单，把文件放进对应文件夹；
3. 双击 `Fwoign.exe` 启动。

目录结构应当是：

```
Fwoign\
├── Fwoign.exe            主程序（必需，发行包自带）
├── lib\HandyControl.dll  界面库（必需，发行包自带）
├── Boot\                 引导文件（需自行放入；default.ipxe / autoexec.ipxe 由程序生成）
├── PXE\                  Tiny PXE Server（需自行放入）
├── NFS\                  haneWIN NFS Server（需自行放入，商业软件）
├── tools\                udpcast（需自行放入）
├── Images\               镜像目录（程序自动创建）
├── config\               配置目录（程序自动创建）
└── log\                  日志目录（程序自动创建）
```

### 已验证可用的版本

下表是本项目开发与实测时使用的版本，可作为「能正常工作」的参照：

| 组件 | 已验证版本 | 依据 |
|---|---|---|
| Tiny PXE Server | **1.0.0.23** | `pxesrv.exe` 的文件版本属性 |
| haneWIN NFS Server | **1.2.70** | `nfssrv-64.exe` 的文件版本属性 |
| FOG FOS（`bzImage` / `init.xz`） | **FOG 1.5.x 系列** | initramfs 内置脚本的版本注记 |
| udpcast（`udp-sender` / `udp-receiver`） | **2023-09-24 构建** | 二进制内嵌的构建日期 |
| iPXE（`undionly.kpxe` / `ipxe.efi`） | 未标注 | 二进制内无可读版本串，请以校验值为准 |

关于 FOS 内核版本：

> **理论上任何原版 FOS 都可以使用**——Fwoign 只按约定调用 FOS 的成像脚本与 partclone，
> 不修改、不依赖特定补丁。但需要说明：**我们只在上面列出的版本上实际验证过**。
> 若你使用更新或更旧的 FOS，多数情况下仍可正常工作；一旦出现异常，
> 请先换回表中版本复测，以排除版本差异。

### 关于 `default.ipxe`、`autoexec.ipxe`（程序自动生成，不要手动放入）

`Boot\` 下的这两个文件**不是需要你下载的**，而是程序每次点「开始」时按当前任务生成的：

| 文件 | 作用 | 内容来源 |
|---|---|---|
| `default.ipxe` | iPXE 启动脚本：决定客户端是进入还原还是备份、内核参数、镜像名 | 由程序根据界面上的选择生成 |
| `autoexec.ipxe` | FOS 进入系统后自动执行的脚本：拉取镜像、调用 partclone 写盘/读盘 | 同上 |

它们会被**每次启动服务时覆盖重写**，所以：

- 不要手动放入或修改，改了也会被覆盖；
- 如果这两个文件缺失或损坏，点「开始」后会自动重建，不需要手工处理。

同理，`PXE\config.ini`、`NFS\nfsd.ini`、`NFS\exports`、`NFS\inodes.nfs` 也都是程序运行时生成的，
不要从其它机器拷贝（里面的路径是绝对路径，会指向错误位置）。

## 三、各组件从哪获取

### 1. iPXE 引导文件（`Boot\undionly.kpxe`、`ipxe.efi`）

https://boot.ipxe.org/

- `undionly.kpxe` —— 传统 BIOS 客户端使用；
- `ipxe.efi` —— UEFI 客户端使用（64 位）。

程序按客户端的 PXE 架构号自动选择这两者之一，**不需要 `snponly.efi`**，也不用准备它。

直接把三个文件下载到 `Boot\` 即可。若只服务一种引导方式，只放对应的那一份也能运行。

### 2. FOS 内核与 initramfs（`Boot\bzImage`、`Boot\init.xz`）

这两个文件来自 **FOG Project** 的 FOS（Fog Operating System）：

- 源码与构建：https://github.com/FOGProject/fos （按该仓库 README 构建，产物即 `bzImage` 与 `init.xz`）；
- 或者从已安装的 FOG 服务器上取：FOG 安装目录下 `.../service/ipxe/` 目录内含 `bzImage`、`init.xz`。

> 注意：这是**整盘成像的引擎**（内含 partclone）。建议使用与下表「已验证可用的版本」同代的 FOS；
> 不同版本的 FOS 多数仍可正常工作，但本项目只在表中版本上实际验证过。

### 3. Tiny PXE Server（`PXE\pxesrv.exe`）

原始发布页：<http://reboot.pro/files/file/303-tiny-pxe-server/>
（该站点近年时常无法访问，实测目前已连不上。）

**可用的下载来源**（任选其一，都是同一个程序）：

| 来源 | 地址 | 说明 |
|---|---|---|
| GitHub 镜像仓库 | <https://github.com/erwan2212/tinypxeserver> 根目录 `pxesrv.zip` | 解压出 `pxesrv.exe`。实测其文件版本为 **1.0.0.23**，与本项目验证过的版本号一致（文件大小 948,736 字节，与本项目使用的 926,208 字节略有差异，属同版本不同打包） |
| 网页存档 | <https://web.archive.org/web/2023/http://reboot.pro/files/file/303-tiny-pxe-server/> | **只能查看页面，无法下载文件**，仅作版本信息参考 |

下载后把 `pxesrv.exe` 放到 `PXE\`。首次启动时程序会自动在同目录生成 `config.ini`，
**不要**手动拷贝别的机器的 `config.ini`（其中的路径是绝对路径）。

参考校验：文件大小 926,208 字节，SHA-256 前 16 位 `1bb9eb7eff5f4de3`。

### 4. haneWIN NFS Server（`NFS\` 整个目录）

**这是商业软件，必须自行购买授权**（官网提供试用版，未注册时传输时长/功能受限）。

获取步骤：

1. 打开官网 <https://www.hanewin.net/nfs-e.htm>，下载对应版本的压缩包，
   例如 1.2.70 版：<https://r.hanewin.net/nfs1270.zip>；
2. 解压后把**压缩包内的全部内容**复制到程序目录的 `NFS\`（保持原目录结构，含 `doc\` 等子目录）；
3. **不要**复制或新建 `nfsd.ini`、`exports`、`inodes.nfs`：这三个由 Fwoign 在运行时生成，
   里面是绝对路径，从别的机器拷过来会指向错误位置。

### 5. udpcast（`tools\udp-sender.exe`、`udp-receiver.exe`）

https://www.udpcast.linux.lu/download

下载 Windows 版本压缩包，解出其中这两个 exe 放到 `tools\`。

> 多播还原时使用；单播还原/备份不依赖它们，但缺少时「刻台数 ≥ 2」会启动失败。

## 四、放入后的自检

启动 `Fwoign.exe` 后看 `log\detail-年-月-日.log`，正常应能看到类似：

```
程序：D:\Fwoign
网卡：Realtek ... / 连接名 以太网 / MAC ... / IP ...
```

点「开始」后若提示缺少文件，日志里会给出具体是哪一个路径不存在。常见现象：

| 现象 | 缺少的文件 |
|---|---|
| 客户端 PXE 有响应但立刻退回 | `Boot\undionly.kpxe` 或 `ipxe.efi` |
| 客户端加载内核后报错、无进度 | `Boot\bzImage` / `Boot\init.xz` |
| 点开始提示 NFS 启动失败 | `NFS\nfssrv-64.exe` |
| 多播时提示找不到发送端 | `tools\udp-sender.exe` |
| 完全拿不到 IP | `PXE\pxesrv.exe` 或本机 IP 配置 |
