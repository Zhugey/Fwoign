# Fwoign

Windows 原生的局域网整盘网刻服务端：**PXE + iPXE + FOG 的 FOS 成像引擎（partclone）+ haneWIN NFS**。
在 Windows 10/11 上批量备份 / 还原整盘，不需要任何 Linux 服务端。

当前版本：**V1.0.0**

---

## ⚠️ 先读这一段

本仓库**只包含程序源码**，发行包**只包含主程序与空目录**。
运行所需的第三方文件（引导镜像、PXE 服务、NFS 服务、多播工具）需要你自己准备，
具体清单、获取地址与放置位置见 **[docs/运行文件说明.md](docs/运行文件说明.md)**。

其中 **haneWIN NFS Server 是商业软件，必须自行购买授权**（<https://www.hanewin.net/nfs-e.htm>）。
本项目不分发它，也不提供任何授权信息。

## 构建

需要 Windows + .NET SDK（目标框架 4.8）：

```powershell
dotnet build src\Fwoign.csproj -c Release
```

产物在 `src\bin\Release\net48\`。

程序清单要求管理员权限（需改网卡 IP、启动 DHCP/TFTP/NFS 服务、绑定 80 端口）。

**本地调试**：把运行文件放到仓库的 `runtime-local\` 下（结构同发行包）。
程序启动时会自动识别该目录作为程序根，无需手工拷贝到输出目录。

## 打包

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build-release.ps1 -Version 1.0.0
```

脚本会：编译 → 组装 `dist\Fwoign\`（主程序 + 文档 + 空运行目录）→ 输出 `dist\Fwoign-V1.0.0-日期.zip`。
`runtime-local\` 中的文件**不会**被打进发行包。

# 使用教程

## 一、准备

### 1. 硬件与网络

| 项目 | 要求 |
|---|---|
| 服务端 | Windows 10 / 11 机器，至少一张有线网卡（无线不可用于 PXE） |
| 网络 | 服务端与客户端接在**同一交换机、同一网段**；不要跨路由器 |
| 客户端 | 支持 PXE 启动，BIOS/UEFI 中开启 Network Boot |
| 存储 | 服务端预留足够空间放镜像，建议单机 ≥ 60 GB |

### 2. 软件准备

1. 把发行包解压到任意目录（不要放在 `Program Files` 这类受保护路径，否则配置与日志无法写入）；
2. **按 `docs\运行文件说明.md`（或同名 PDF）放好运行文件**——每个运行目录里还附了
   「放入说明.txt」，逐项写明了文件名、作用和下载地址；这一步不做，程序无法开始网刻；
3. 完成 haneWIN NFS 的授权注册；
4. 双击 `Fwoign.exe`，UAC 弹窗选择「是」。

> 程序是**单实例**：已经在运行时再次双击，会提示「Fwoign 已经在运行」并退出。
>
> 每次启动都会自检运行文件（引导、内核、PXE、NFS、多播工具）。缺失时会弹出清单，
> 写明缺什么、该放哪个目录、从哪里获取，并提供「查看说明文档」按钮；不影响先打开界面查看。

## 二、首次配置

### 1. 选择网卡

「网卡」下拉框列出所有**已连接**的有线网卡（连接名 + MAC + 当前 IP）。
列表为空说明网线未插好、网卡被禁用，或该网卡类型不被识别。

### 2. 选择网络环境

| 模式 | 适用场景 | 谁分配 IP | 本机 IP 会被改吗 |
|---|---|---|---|
| **纯交换机（本机 DHCP）** | 局域网里**没有**其它 DHCP 服务器 | 本机 Tiny PXE 分配，`192.168.x.2` 起共 253 个 | **会**，启动时设置，退出时自动还原 |
| **有路由器（ProxyDHCP）** | 局域网里**已有**路由器在发 DHCP | 现有 DHCP 分配，本机只补充 PXE 引导信息 | **不会**，使用网卡当前地址 |

判断方法：这台 Windows 平时靠路由器自动获取 IP 上网，就选「有路由器」；拿交换机直连、专门做网刻，选「纯交换机」。

> 选错的表现：纯交换机模式会改掉本机 IP，若该网段已有路由器 DHCP，会出现两个 DHCP 应答，客户端 PXE 可能失败。

### 3. 设置服务器 IP（仅纯交换机模式）

- 前三段与客户端所在网段一致，第四段建议 `1`（例：`192.168.55.1`）；
- 掩码固定 `255.255.255.0`，程序会拒绝非法地址（`.0`、`.255`、`127.x`、`169.254.x` 等）；
- 若地址尚未生效就点「开始」，会提示等待 1~3 秒再试。

## 三、整盘还原

1. 切到 **「整盘还原」** 页签；
2. 第一行「镜像目录」确认路径（默认 `程序目录\Images`），右侧按钮为「浏览」「刷新」「打开目录」；
3. 左半边列表点选一个镜像，右半边显示该镜像信息；
4. 设置 **刻台数**：`1` = 单播；`≥2` = 多播（同一份数据只发一次）。旁边的循环箭头按钮可一键恢复为 1；
5. 点右上角 **「开始还原」**；
6. 客户端开机按 PXE 启动（常见 `F12` / `F11` / `Esc`）。

### 界面说明

| 列 | 含义 |
|---|---|
| 状态 | 等待中 / 进行中 / 无响应 / 已完成 / 已停止 / 出错 |
| 进度 | 「分区 3/4」表示当前分区，进度条为**当前分区**百分比 |
| 已拷贝/总量 | 当前分区已写 / 该分区总量；完成后显示「总量/总量」 |
| 用时 / 剩余 | 每秒刷新 |
| 结果 | 成功绿色，失败红色并给出原因 |

### 多播要点

- 点「开始还原」后进入**等待成员**阶段，显示「已到 N/M 台」；
- 到齐自动开始；不想等可点 **「直接开始」**；
- 名额固定：会话开始后再启动的机器不会加入；
- 某台中途断电/断网：重传无应答后剔除，其余机器继续；
- 分区切换最多等 15 秒。

## 四、整盘备份

1. 切到 **「整盘备份」** 页签；
2. 确认「镜像目录」；
3. 填写 **备份名称**：只能英文、数字与 `-` `_` `.`，**不能用中文**；不能以 `.` 开头；目录下已有同名镜像会被拦下；
4. 点「开始备份」，客户端 PXE 启动并进入备份；
5. 完成后状态变为「已完成（停止服务时归档为镜像）」，此时 **点「停止」** 才会把 `Images\<MAC>` 归档为正式镜像；
6. 备份中断：未写完的目录会被自动清理。

> 备份是单机任务，不支持多播。

## 五、停止与退出

- **停止**：中断当前任务，客户端需重新从 PXE 启动；多播任务停止后客户端不会自动退出。
- **关闭窗口**：停服务 → 还原网卡 IP（纯交换机模式）→ 退出。关闭过程中重复点击会被忽略。
- 任务无论成功失败都**不会自动停服务**，需手动点「停止」。

## 六、界面布局

| 区域 | 说明 |
|---|---|
| 备份还原区 | 镜像目录、镜像列表、还原/备份设置 |
| 客户端列表 | IP、MAC、状态、分区进度、速率、用时、剩余、结果 |
| 运行日志 | 当前任务的简要过程 |

区域之间有分隔条（平时透明、鼠标移上去显色）；备份还原区与日志区默认取最小高度（290 / 130），
剩余高度全部给客户端列表；拖动后的高度会被记住。

## 七、文件与日志

| 路径 | 内容 |
|---|---|
| `Images\` | 镜像目录（每个子目录一个镜像） |
| `config\settings.ini` | 界面设置（网卡、IP、路径、台数、窗口高度） |
| `config\tuning.ini` | 可调参数（带中文注释，首次运行生成） |
| `config\ipbackup.ini` | 网卡原始 IP 记录，退出时用于还原 |
| `log\task-年-月-日.log` | 任务级日志 |
| `log\detail-年-月-日.log` | 详细日志（排查用） |

反馈问题时请把当天两个日志一起提供。

## 八、常见问题

**Q：点「开始」提示缺少文件 / 服务启动失败**

按 `docs\运行文件说明.md` 检查对应目录是否放齐，日志会给出具体缺失路径。

**Q：客户端 PXE 启动后拿不到 IP**

1. 看日志「PXE 绑定校验：期望 X，实际绑定 Y」——绑到 `127.0.0.1` 说明 IP 未生效，停止后稍等再开始；
2. 纯交换机模式确认没有第二个 DHCP；
3. 有路由器模式确认路由器未拦截 PXE。

**Q：客户端提示 `Unable to locate image store`**

镜像名含中文，或镜像文件不完整。用英文名重新备份。

**Q：还原完成后只写入了第一个分区**

镜像不完整。检查 `d1p*.img` 数量是否与 `d1.partitions` 中的分区数一致。

**Q：能同时开两个程序吗**

不能。再次双击会提示「Fwoign 已经在运行」。
