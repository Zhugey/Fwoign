# Fwoign

Windows 原生的局域网整盘网刻服务端：**PXE + iPXE + FOG 的 FOS 成像引擎（partclone）+ haneWIN NFS**。
在 Windows 10/11 上批量备份 / 还原整盘，不需要任何 Linux 服务端。

当前版本：**V1.2.3**

## 目录结构

```
Fwoign\
├── Fwoign.exe            主程序（双击运行，需要管理员权限）
├── Boot\                 Tiny PXE 的 TFTP 根目录
│   ├── undionly.kpxe       BIOS 客户端 → iPXE
│   ├── ipxe.efi            UEFI 客户端 → iPXE
│   ├── snponly.efi         UEFI 备选（部分固件用，默认不启用）
│   ├── bzImage             FOS 的 Linux 内核
│   ├── init.xz             FOS initramfs（含 partclone / udp-receiver）
│   ├── default.ipxe        每次启动自动生成
│   └── autoexec.ipxe       每次启动自动生成
├── NFS\                  haneWIN NFS Server（官方原版）
│   ├── nfssrv-64.exe
│   ├── nfsd.ini            首次运行自动生成（不含授权信息）
│   └── exports             每次启动自动生成
├── PXE\                  Tiny PXE Server
│   ├── pxesrv.exe
│   └── config.ini          每次启动自动生成
├── tools\                udp-sender.exe / udp-receiver.exe（udpcast）
├── lib\                  运行库
├── Images\               镜像目录（默认位置，不随仓库发布）
├── config\               本机设置与 IP 备份（不随仓库发布）
├── log\                  运行日志（不随仓库发布）
└── GUI\                  源代码（WPF / .NET Framework 4.8）
```

## 构建

需要 Windows + .NET SDK（目标框架 4.8）：

```powershell
cd GUI
dotnet build Fwoign.csproj -c Release
```

产物在 `GUI\bin\Release\net48\Fwoign.exe`，覆盖到程序根目录即可。
程序清单要求管理员权限（需改网卡 IP、启动 DHCP/TFTP/NFS 服务、绑定 80 端口）。

# 使用教程

## 一、准备

### 1. 硬件与网络

| 项目 | 要求 |
|---|---|
| 服务端 | Windows 10 / 11 机器，至少一张有线网卡（无线不可用于 PXE） |
| 网络 | 服务端与客户端接在**同一交换机、同一网段**；不要跨路由器 |
| 客户端 | 支持 PXE 启动，BIOS/UEFI 中开启 Network Boot |
| 存储 | 服务端预留足够空间放镜像，建议单机 ≥ 60 GB |

### 2. 软件准备

1. 把发行包解压到任意目录（不要放在 `Program Files` 这类受保护路径，否则配置与日志无法写入）；
2. 首次运行前按 haneWIN 官方说明完成 **NFS 授权注册**（未注册会在传输中受限）；
3. 双击 `Fwoign.exe`，UAC 弹窗选择「是」。

> 程序是**单实例**：已经在运行时再次双击，会提示「Fwoign 已经在运行」并退出，不会开出第二个界面。

## 二、首次配置

### 1. 选择网卡

「网卡」下拉框列出所有**已连接**的有线网卡（连接名 + MAC + 当前 IP）。
列表为空说明网线未插好、网卡被禁用，或该网卡类型不被识别。

### 2. 选择网络环境（决定勾哪个单选框）

| 模式 | 适用场景 | 谁分配 IP | 本机 IP 会被改吗 |
|---|---|---|---|
| **纯交换机（本机 DHCP）** | 局域网里**没有**其它 DHCP 服务器 | 本机 Tiny PXE 分配，`192.168.x.2` 起共 253 个 | **会**，启动时设置，退出时自动还原 |
| **有路由器（ProxyDHCP）** | 局域网里**已有**路由器/防火墙在发 DHCP | 现有 DHCP 分配，本机只补充 PXE 引导信息 | **不会**，使用网卡当前地址 |

判断方法：这台 Windows 平时靠路由器自动获取 IP 上网，就选「有路由器」；拿交换机直连、专门做网刻，选「纯交换机」。

> 选错的表现：纯交换机模式会改掉本机 IP，若该网段已有路由器 DHCP，会出现两个 DHCP 应答，客户端 PXE 可能失败。

### 3. 设置服务器 IP（仅纯交换机模式）

- 前三段与客户端所在网段一致，第四段建议 `1`（例：`192.168.55.1`）；
- 掩码固定 `255.255.255.0`，程序会拒绝非法地址（`.0`、`.255`、`127.x`、`169.254.x` 等）；
- 若地址尚未生效就点「开始」，会提示等待 1~3 秒再试。

## 三、整盘还原

### 操作步骤

1. 切到 **「整盘还原」** 页签；
2. 第一行「镜像目录」确认路径（默认 `程序目录\Images`），右侧三个按钮分别是「浏览」「刷新」「打开目录」；
3. 左半边列表点选一个镜像，右半边显示该镜像信息；
4. 设置 **刻台数**：
   - `1` = 单播，只服务一台；
   - `≥2` = 多播，同一份数据只发一次，所有机器同时接收；
   - 多播做完想回到单机，点旁边的**循环箭头按钮**一键恢复为 1；
5. 点右上角 **「开始还原」**；
6. 客户端开机按 PXE 启动（常见按键 `F12` / `F11` / `Esc`，或在 BIOS 中把 Network Boot 调到第一位）；
7. 客户端拿到 IP、加载引导文件后，自动进入 FOS 环境写盘。

### 界面说明

| 列 | 含义 |
|---|---|
| 状态 | 等待中 / 进行中 / 无响应 / 已完成 / 已停止 / 出错 |
| 进度 | 「分区 3/4」表示当前在第几个分区（ESP、MSR、C、D 各算一个），进度条是**当前分区**的百分比 |
| 已拷贝/总量 | 当前分区的已写字节 / 该分区总量；判定完成后统一显示「总量/总量」 |
| 用时 / 剩余 | 每秒刷新，剩余按当前速率估算 |
| 结果 | 成功为绿色，失败为红色并给出原因 |

### 多播要点

- 点「开始还原」后进入**等待成员**阶段，界面显示「已到 N/M 台」；
- 到齐自动开始；不想等可点 **「直接开始」**，按已到齐台数立即发送；
- 名额固定：会话开始后再启动的机器**不会**加入，需要重新开始任务；
- 某台中途断电/断网：发送端连续重传无应答后将其剔除，其余机器继续；
- 分区切换最多等 15 秒，不会因掉线机器拖住整队。

## 四、整盘备份

1. 切到 **「整盘备份」** 页签；
2. 确认「镜像目录」（镜像写到这里）；
3. 右半边填写 **备份名称**：
   - 只能英文、数字与 `-` `_` `.`，**不能用中文**（FOS 控制台不支持，会显示成 `??` 并导致还原失败）；
   - 不能以 `.` 开头，不能是 `.` 或 `..`；
   - 该目录下**已存在同名镜像会被直接拦下**，不会覆盖旧镜像；
4. 点「开始备份」，客户端 PXE 启动并自动进入备份；
5. 备份完成后状态变为「已完成（停止服务时归档为镜像）」，此时 **点「停止」**：
   - 程序把 `Images\<MAC>` 归档为你填的镜像名；
   - 归档采用「旧镜像改名 `.old-时间戳` → 移入新镜像 → 成功后删除 `.old`」，中途失败自动回滚；
6. 备份中断（断网、点停止、出错）：未写完的 `Images\<MAC>` 目录会被自动清理。

> 备份是**单机**任务，不支持多播（多播只用于还原）。

## 五、停止与退出

- **停止**：点右上角「停止」。会中断当前任务，客户端需重新从 PXE 启动再执行一次；多播任务停止后客户端不会自动退出，需要手动重启那些机器。
- **关闭窗口**：依次停服务 → 还原网卡 IP（纯交换机模式）→ 退出。关闭过程中重复点击关闭会被忽略。
- **IP 还原**：即使网线被拔掉或网卡被禁用，退出时也会尝试还原；失败会弹窗提示手动改回。
- 任务无论成功还是失败都**不会自动停服务**，需要手动点「停止」。

## 六、界面布局

| 区域 | 说明 |
|---|---|
| 备份还原区 | 镜像目录、镜像列表、还原/备份设置 |
| 客户端列表 | IP、MAC、状态、分区进度、速率、用时、剩余、结果 |
| 运行日志 | 当前任务的简要过程 |

三个区域之间有分隔条可拖动；**备份还原区**与**日志区**默认取最小高度（290 / 130），剩余高度全部给客户端列表。
拖动后的高度会被记住，下次打开保持上次的设置。

## 七、文件与日志

| 路径 | 内容 |
|---|---|
| `Images\` | 镜像目录（每个子目录一个镜像，含 `d1.mbr`、`d1.partitions`、`d1p*.img`） |
| `config\settings.ini` | 界面设置（网卡、IP、路径、台数、窗口高度等） |
| `config\ipbackup.ini` | 网卡原始 IP 记录，用于退出时还原 |
| `log\task-年-月-日.log` | 任务级日志（界面可见内容） |
| `log\detail-年-月-日.log` | 详细日志（排查用） |

反馈问题时请把当天这两个日志一起提供。

## 八、常见问题

**Q：客户端 PXE 启动后拿不到 IP**

1. 看日志里有没有「PXE 绑定校验：期望 X，实际绑定 Y」——绑定到 `127.0.0.1` 说明启动时本机 IP 还没生效，停止后稍等再开始；
2. 纯交换机模式确认局域网里没有第二个 DHCP；
3. 有路由器模式确认路由器未拦截 PXE。

**Q：客户端提示 `Unable to locate image store`**

镜像名含中文，或镜像目录文件不完整。用英文名重新备份。

**Q：还原完成后只写入了第一个分区**

镜像不完整（备份时中断过）。检查 `d1p*.img` 数量是否与 `d1.partitions` 里的分区数一致。

**Q：多播时一台出错，其它机器等很久**

掉线机器会在重传耗尽后被剔除，分区切换最多等 15 秒。彻底卡死时可直接「停止」重来。

**Q：点「开始」没反应**

看状态栏与日志：常见原因是「上一次启动还没完成」「IP 尚未生效」「80 端口被其它网页服务占用」。

**Q：关闭程序后网卡 IP 没还原**

程序会弹窗告知失败原因；可手动到「网络连接 → 属性 → IPv4」改回，或使用界面上的「还原 IP」按钮。

**Q：能同时开两个程序吗**

不能。再次双击会提示「Fwoign 已经在运行」，请使用已打开的窗口。
